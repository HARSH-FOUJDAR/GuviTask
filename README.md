# AuthSystem

A simple user authentication system built using PHP, MySQL, HTML, CSS, JavaScript, jQuery, and Bootstrap.

## Features

* User Registration
* User Login
* User Logout
* User Profile
* Update Profile
* Password Hashing
* MySQL Database

## Technologies Used

* HTML
* CSS
* JavaScript
* jQuery
* Bootstrap
* PHP
* MySQL
